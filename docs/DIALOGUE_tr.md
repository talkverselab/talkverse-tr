# 회화 — 튀르키예어 특이점

**공통 원칙은 https://talkverse.uk/talkverse/dialogue-rules/ 를 따른다**(2026-11-02 확정 — 레벨 = 절벽 R1~R4, 턴 수, 말투, 반전, 수위, 검수 등).
절벽 구간표: https://talkverse.uk/cliff/18/ · 이 앱의 구간 단어 = `assets/data/freq/lang_es_top.csv`(기본형 + 접미사 기준 R1 1–119 · R2 –157 · R3 –282 · R4 –568 · R5 –2,000).
작성 규칙 = `tools/prompts/dialogue_tr.md`, 검사 = `tools/check_dialogues.py`, 독음 = `tools/rd_tr.py`.
**회화 어휘 상한(2026-11-07):** 절벽 R1(119위)은 대부분 기능어·접미사라 문장이 안 되므로 회화는 R1 ≤568 · R2 ≤1,000 · R3 ≤2,000 위로 쓴다.
이 문서에는 튀르키예어만의 것만 적는다.

## 1. 기본 변이
- **표준 튀르키예어(이스탄불 말, `tr_TR`)** 하나. 다른 변이(키프로스·아제르바이잔 쪽 등)는 만들지 않는다 — 필요해지면 별도 파일.

## 2. 성별판
- **없음(한 판).** 문법 성이 없고 3인칭 대명사 `o` 도 남녀 구별이 없다. 학습자 성별로 바뀌는 말이 없다.
- 호칭만 관계에 따라 고른다: 친구 이름 그대로, 손윗사람 `abi`(형·오빠)/`abla`(누나·언니), 낯선 어른 `Bey`/`Hanım`(이름 뒤), 가게 `abi`·`abla` 도 흔하다.

## 3. 말투 (원칙 §5 의 튀르키예어판)
- 반말 = `sen`·2인칭 단수 어미(`-sın`), 존댓말 = `siz`·2인칭 복수 어미(`-sınız`) + `lütfen`·`Affedersiniz`.
- 가까워지는 전환 장면: `Bana sen diyebilirsin.`(편하게 말해도 돼) 같은 한 턴으로 보여 준다.

## 4. 턴 길이 (원칙 §4)
단어 수(띄어쓰기 기준, 구두점 제외). 교착어라 한 단어에 뜻이 많이 들어가므로 짧게 잡는다.

| 구간 | 한 턴 단어 수 | 한 턴 문장 수 |
|---|---|---|
| R1 | 2–7 (1단어 단답 금지) | 1–2 |
| R2 | 3–10 | 1–2 |
| R3·R4 | 4–14 | 1–3 |

## 5. 한글 독음 표기표 (`rd`, 원칙 §7)
소리 나는 대로, 음절마다 한글 한 글자. 받침은 음절 끝 자음(`ben` 벤, `gün` 귄)으로 쓴다.

| 글자 | 독음 | 예 |
|---|---|---|
| a · e · i · o · u | 아 · 에 · 이 · 오 · 우 | `evet` 에벳 |
| **ı** | 으 | `adım` 아듬, `ısmarlamak` 으스마를라막 |
| **ö** | 외 | `öğrenmek` 외렌멕 |
| **ü** | 위 | `gün` 귄, `lütfen` 뤼트펜 |
| c · **ç** | ㅈ · ㅊ | `cuma` 주마, `çay` 차이 |
| **ş** | ㅅ + 반모음: şa 샤 · şe 셰 · şı/şi 시 · şo 쇼 · şu 슈 · şü 쉬, 받침·자음 앞은 시 | `şehir` 셰히르, `çalışıyorum` 찰르시요룸 |
| **ğ** | 소리 없음(앞 모음을 늘이거나 이어 읽음) — 한글로 쓰지 않는다 | `öğreniyorum` 외레니요룸, `dağ` 다 |
| j | ㅈ | `jüri` 쥐리 |
| y | 반모음(야·예·요·유…), 받침 자리는 이 | `ayran` 아이란, `yok` 욕 |
| h | ㅎ (모음 뒤 받침 자리도 흐) | `kahve` 카흐베 |
| r | ㄹ, 낱말 끝·자음 앞은 르 | `bir` 비르, `merhaba` 메르하바 |
| l | ㄹ(모음 사이 ㄹㄹ) | `selam` 셀람 |
| k · g · p · b · t · d | ㅋ · ㄱ · ㅍ · ㅂ · ㅌ · ㄷ | |
| s · z | ㅅ · ㅈ | `gezmek` 게즈멕 |
| v · f | ㅂ · ㅍ | `favori` 파보리 |
| m · n | ㅁ · ㄴ (받침 가능) | |
| 자음 둘 이상 이어짐 | 앞 자음은 받침, 나머지는 '으' 붙여 음절로 | `Türkçe` 튀르크체 |

- 낱말 사이 띄어쓰기·구두점은 원문을 따른다. 고유명사도 같은 표를 쓴다(`İstanbul` 이스탄불).
- 검사기는 이 표로 `rd` 를 다시 만들어 원문과 어긋나는 턴을 표시한다. 알려진 어긋남: L1 ep1 `çalışıyorum` → 지금 `찰르셔룸`(표대로면 `찰르시요룸`).

## 6. 정리할 템플릿 잔재 (원칙 §12)
- 대상어 칸 이름 `es`, 홈 인사 `¡Hola!`, 오늘의 학습 `PRINCIPIANTE 1`, 준비중 메뉴 「성·수」(`el/la`)·「발음 (rr · ñ · 강세)」.
  튀르키예어에 맞게: 인사 `Merhaba!`, 라벨은 구간(R1…), 「성·수」 → 모음조화, 「발음」 → ı·ğ·ş 등.
- 회화 `L1.json` 의 L 레벨 → 어휘 상한으로 R 을 다시 매긴다(원칙 §2). 지금 5편은 초안(draft).
